# Privacy Policy

Last updated: February 2026

This privacy policy applies to the browser extension "PoorSearch" (the "Extension").

## Data Collection

The Extension does not collect, store, transmit, or share any personal data or user information.

## Local Processing

All functionality of the Extension runs entirely locally in the user's browser.
No data is sent to any external servers.

## Permissions

The Extension requires access to Google Search pages solely to detect and remove AI-generated overview blocks.
This access is used only for the core functionality of the Extension.

## Third Parties

The Extension does not use third-party analytics, tracking tools, or advertising services.

## Changes

If this privacy policy changes, the updated version will be published at this URL.

## Contact

If you have any questions about this privacy policy, you can contact the developer via the project's GitHub repository.
